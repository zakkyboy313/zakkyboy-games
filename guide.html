Install & update games

No software needed. It all happens in the browser.

  1. Open the Games page in Chrome or Edge on a computer.
  2. Plug in your ZakkyBoy with a USB-C data cable.
  3. Open a game, click Install, pick the port that appears, then Connect.
  4. Wait for Installation complete, then press reset.

Updating a game

Games get better over time. To get the latest version, just click Install on it again. It replaces whatever is on the console.

No port in the list?

Try another cable (some only charge). Or hold BOOT on the board while plugging in, then click Install again.

Buttons don't respond?

Your buttons are on different pins from the ones listed on the game. Ask Zak for a version built for your wiring.

One game at a time

Installing a game replaces the one on the console. Zakky Pixel + Zakky Gun puts two on at once.

Got a .bin file?

Every game also has a .bin download. It can be flashed at address 0x0 with any ESP32 web flasher.

Make your own ZakkyBoy game

This is how every game on this site was made: build a playable prototype in the browser with an AI chatbot (Claude, ChatGPT, Gemini…), play it until it's fun, then have the AI turn it into code for the console. You don't need to know how to code.

Flash it onto your ZakkyBoy

        
You do this once with the free Arduino IDE. After the first time, it's just steps 5 to 7.

        
    
          
  1. Download and install Arduino IDE 2.
    2. 
          
  2. Go to File → Preferences (on a Mac: Arduino IDE → Settings). In Additional boards manager URLs, paste:
    https://espressif.github.io/arduino-esp32/package_esp32_index.json
    3. 
          
  3. Open Tools → Board → Boards Manager, search esp32, and install esp32 by Espressif Systems.
    4. 
          
  4. Open Tools → Manage Libraries, search U8g2, and install it (plus anything else the AI listed).
    5. 
          
  5. Open your my_game.ino. Choose Tools → Board → esp32 → XIAO_ESP32C3.
    6. 
          
  6. Plug in your ZakkyBoy with a data cable and pick its port under Tools → Port.
    7. 
          
  7. Click Upload (the → arrow). When it says Done uploading, your game starts.
    8. 
        

        
Red error text? Copy all of it into your AI chat with "This didn't compile, please fix it" and upload the new version. Can't find the board? Hold BOOT while plugging in, then upload again.

Made something you're proud of? Send it in. If it's accepted, it goes on the Community page with your name on it, so anyone can play it in the browser and install it.
