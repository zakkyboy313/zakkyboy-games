ZAKKYBOY GAMES

Games for the ZakkyBoy handheld. Pick one, click Install, and it goes straight onto your console.

How to install
  1. Use Chrome or Edge on a computer (Safari and phones can't do this).
  2. Plug your ZakkyBoy into the computer with a USB-C data cable.
  3. Click Install on a game, choose the port that appears (often "USB JTAG/serial debug unit"), then Connect and Install.
  4. Wait for "Installation complete", then unplug or press reset. One game is on the console at a time; installing another replaces it.

Not working? If no port appears: try another cable (some only charge), or hold the BOOT button on the board while plugging it in, then click Install again. If a game installs but the buttons do nothing, your buttons are on different pins from the ones listed; ask Zak for a version built for your wiring.
